# Gray Area — Gray Zone Warfare Tools

**Website:** https://gwazyjustcause.github.io/GrayArea/

The site is built around three tools, without separate patch-explainer pages:

- **[Money](https://gwazyjustcause.github.io/GrayArea/money.html)** — item sale values, price per inventory slot, bag value, and repair profit.
- **[Hideout](https://gwazyjustcause.github.io/GrayArea/hideout.html)** — upgrades per station/level and a synced material stash.
- **[Weapons & Ammo](https://gwazyjustcause.github.io/GrayArea/weapons.html)** — choose ammo by weapon and target armour, with local editable recommendations.
- **[Armory](https://gwazyjustcause.github.io/GrayArea/armory.html)** — interactive 3D WebGL weapon and attachment resale builder. Includes generic original 3D placeholders plus optional licensed GLB models uploaded through the Admin; link assembled weapons to Money.
- **[Loot prices](https://gwazyjustcause.github.io/GrayArea/loot.html)** — community-sourced item reference catalogue.

## Administration

A separate unlisted `admin.html` page is available with GitHub owner authorization. Administrators can edit prices, names, images and licensed GLB weapon models, publish changes and move items to a recoverable Trash bin. Trashed items are not shown in public Money or Loot Prices.

## Accuracy

New items and mechanics are based on available information from Rogue Ops 0.5. Older wiki pricing is a **reference**, not a guarantee for the current update. The catalogue may sync automatically from [GZW Data](https://github.com/ZoniBoy00/gzw-data). A recent sync timestamp does not certify that an individual price is current.

Hideout progress and personal weapon/ammo and item-price changes are saved locally in the browser; clear storage can erase them.

## Publishing

Static site on GitHub Pages. The independent game data source is community maintained. Gray Area is an unofficial fan project and is not affiliated with MADFINGER Games.

## 3D asset rights

The interactive Armory uses the independently written Three.js viewer and original generic 3D references when no approved model is associated with an item. An admin can upload a self-made or appropriately licensed `.glb` per weapon. Do not assume models, textures or source code loaded by third-party websites are licensed for copying, even if accessible in browser developer tools. The GZW Loadout site is a separate project and no models were copied from it.
