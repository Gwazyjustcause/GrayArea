# Gray Area — Gray Zone Warfare Field Guide

**Website:** https://gwazyjustcause.github.io/GrayArea/

Independent Gray Zone Warfare field guide updated for **Rogue Ops (Update 0.5)** on 1 November 2026.

## Pages

- [Update 0.5](https://gwazyjustcause.github.io/GrayArea/rogue-ops.html): official launch changes, community field reports and patch notes.
- [Hideout Planner](https://gwazyjustcause.github.io/GrayArea/hideout.html): per-station/per-level upgrades, synchronized stash counters, remaining needs, two-click confirmation and export/import backups. Progress stays in localStorage on the user's device.
- [Make money](https://gwazyjustcause.github.io/GrayArea/money.html): money, materials, crafting and smuggling priorities.
- [Weapons](https://gwazyjustcause.github.io/GrayArea/weapons.html): new 0.5 weapons, roles and acquisition reports.
- [Gear](https://gwazyjustcause.github.io/GrayArea/gear.html): medical, AI, hacking and loadout implications.
- [Vendors](https://gwazyjustcause.github.io/GrayArea/vendors.html): Vulture and community-reported unlocks.
- [Loot database](https://gwazyjustcause.github.io/GrayArea/loot.html): searchable wiki-derived catalogue with historical-price warnings.

## Data freshness

The **automatic catalogue** is sourced from the independent community [GZW Data](https://github.com/ZoniBoy00/gzw-data) API and synchronised into data/catalog.json and data/version.json. Dataset timestamps indicate *scrape recency*, **not** that prices or trader preferences have been verified in the current patch. Update 0.4 values are not presented as verified 0.5 prices.

New patch mechanics use [official MADFINGER patch notes](https://www.grayzonewarfare.com/news/rogue-ops-out-now-changelog). Reddit and wiki tips are marked as community reports when not confirmed by the developer.

## Contributing

The Loot Database's **Add a price** option opens a GitHub Issue with the game version and evidence. Reports require review before joining published data.

## Publishing

Host the static files with GitHub Pages using the configured deployment source. Automated item-data sync can change underlying catalogue snapshots independently of editorial updates.

This is an unofficial fan project and is not affiliated with MADFINGER Games.
